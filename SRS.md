# School LMS — Software Requirements Specification

**Status: NOT FINALIZED.** This document is intentionally a placeholder.

The SRS will define feature scope role by role (Admin, Teacher, Student,
Parent) and will drive the final Prisma schema, the full API route list, and
the feature set. It does not exist yet.

Until this document is written:

- **Do not implement LMS features.** Attendance, gradebooks, assignments,
  timetables, announcements, user-management workflows, enrollment workflows,
  and all other business functionality are out of scope.
- **Do not invent requirements.** Anything undefined is recorded as
  «Deferred pending SRS» — never guessed in code.
- Product decisions (permissions, workflows, academic-year handling, etc.) are
  recorded as «SRS Decision Required» and left open.

The repository currently contains a verified foundation skeleton only — see
`README.md` for what exists and what is deferred.
